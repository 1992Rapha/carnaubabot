Threads Advanced Search

Client-side webapp for searching public Threads posts with boolean expressions.

Webapp only No backend Boolean logic

Search

Uses /threads/user/:username. A public RSSHub instance may rate limit or block some requests.
Expected JSON array or { posts: [...] }. Each post should include text/content/body and optionally url, author, date.
Supported operators: AND, OR, NOT, XOR, parentheses, quoted phrases.
Important API note

Verified historically: the official Threads API has been oriented around account/media publishing and account-managed data, not broad public keyword search across Threads. Because this is a static webapp with no backend, the app defaults to a third-party public feed path (RSSHub) or a user-supplied JSON endpoint.

Uncertainty: availability, CORS, route support, and rate limits depend on the third-party endpoint you use.
